EMSD BEC 2024 第5.4表（印刷页16，PDF第22页）列出：面积大于200 m² 的办公室最大 LPD 为 7.2 W/m²，并列明须设自动照明控制；面积大于15至200 m² 的办公室为 8.5 W/m²。茶水间为 8.5 W/m²。应按守则定义的各具体空间及面积分别判断，不能因租户总面积标为309 m²就自动把所有独立房间归为大于200 m²。灯具功率应包含驱动或镇流器及固定照明相关负荷，实际适用范围、控制及例外须结合第5节逐条检查。LPD 是能耗上限，不是照度设计要求。

## 回路需求电流依据

EMSD Wiring CoP 2025 Code 7B(3)（印刷页63–64，PDF第64–65页）区分标准最终回路和其他最终回路：按 Code 6 设计的标准最终回路需求电流取其过电流保护器额定值；其他回路按所连接设备要求评估，径向插座按插座额定电流、固定设备按额定或正常电流。荧光灯需考虑控制器损耗和谐波；无更精确信息时守则提出不小于1.8的灯管瓦数到VA系数。Code 7B(4) 提及供应多个最终回路的上级回路可按表7(1)对设备需求应用多样性，而不是机械相加各最终回路经保护器额定值表示的电流。实际使用须核对表的场所适用范围和每项设备条件，平衡三相并避免重复应用折减。

## 初步照度敏感性检查

## 进线最大需量：条件性三相算例

核对 EMSD Wiring CoP 2025 Code 7B(3)–(4) 及 Table 7(1)，印刷页63–67（PDF第64–68页）：标准最终回路的电流需求按其过流保护器额定值；上级线路按连接设备及表格的适用类别处理，Table 7(1) 第12项具体以符合 Code 6E 的最终回路需求为基础。此前“不能简单加回路额定值”的意思是不能不加判别和多样率地求和，不能误解为表7(1)第12项从不使用回路需求。表格适用范围及各相需量必须核实。

`data/incoming_demand_scenario.csv` 是非最终算例：假设办公室符合该表的 small offices 类别，且P1–P6均最终能设计成符合Code 6E/表6(1)的32 A标准环路，每相分配两路，则每相插座部分按第12项为 32 + 50%×32 = 48 A。照明分别按28、32、31盏分相，各自按 22.5 W/(230 V×0.9) 换算，再按照明项90%取值；三个局部合计分别约50.74、51.13、51.03 A。此算例暂不考虑FS01固定设备、应急照明、其他固定设备和未来余量；FS01是否独立回路、是否已计入插座回路必须明确，避免漏算或重复计算。

为LC-D的11盏22 W灯提出一个可核资料的候选：Theben `LUXA 103 S360-101-12 AP WH`（1030063）吸顶人体感应器，参考[厂家数据表](https://www.theben.de/product/1030063/datasheet)。该表列230 V AC、50 Hz、待机约0.5 W、灯光延时15秒至30分钟、带按钮手动输入、可全自动或半自动，LED灯每盏大于8 W时典型开关负载400 W，以及500 A/200 μs的浪涌电流上限；其灯光通道可作开关控制，不需要假定3117955驱动具有调光接口。候选记录见 `data/pantry_control_candidate.csv`。

## 茶水间人体感应覆盖几何初查

根据厂家[1030063产品页](https://www.theben.de/en/luxa-103-s360-101-12-ap-wh-1030063)的探测表，在3 m安装高度、21°C规划条件下，坐姿探测区标称直径约5 m，行走探测区更大。将暂定茶水间围框5.900×5.0075 m简化为矩形：对角线约7.739 m，大于5 m，所以不论单个理想圆形坐姿探测区中心如何放置，都不可能把四个角全部覆盖；放在中心时中心到角约3.869 m，超过2.5 m半径。实际人员可能不在所有角落，矩形范围亦非最终实测，故这只排除“一个理想5 m圆覆盖整个矩形”的假设，不证明一个传感器必然不适合实际工况。

`data/pantry_sensor_coverage_scenario.csv` 给出四个均分矩形的几何中心作为研究布点：若四个圆形坐姿探测区在3 m安装高时都具有2.5 m半径、且无墙面与设备遮挡，则各自1/4矩形中距最近中心最远点约1.935 m，理论上覆盖该简化矩形。这不是最小传感器数量证明，也不是实际覆盖验证。厂家说明可并联最多8个探测器，但主从角色、配置、接线、供电、开关浪涌、实际高度和静止人体探测仍需实测和按说明书验证，不将四个几何点作为已选设备或画入正式图。

如仅作为保守比较将四台各0.5 W待机与242 W灯具相加，为244 W，对29.5443 m²约8.26 W/m²；控制器能耗是否及如何计入LPD、实际面积、工作状态均须核实。该较高数量缩小了原来方案的能效余量，应与实际活动区和更适合的产品比较。
